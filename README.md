# 鹈鹕的海岸骑行

一个无需安装依赖、可离线游玩的静态 Web 游戏。戴着骑行帽的鹈鹕骑着薄荷绿单车，沿海岸公路跳过路锥和木箱。画面使用原生 Canvas 绘制，不依赖外部图片、字体、CDN 或网络服务。

## 运行

直接用现代桌面浏览器打开本目录的 `index.html` 即可；使用经典脚本加载，支持 `file://`，不要求启动服务器或构建。也可以由任意静态网站服务器提供本目录。

## 操作

- 点击「开始骑行」出发，或按空格开始。首次空格只开始骑行，不起跳；松开后再按空格才跳跃。
- 骑行时轻按空格跳跃，落地后才能再次起跳；长按不会自动连续跳跃。游戏接管空格的页面滚动行为。
- 看准前轮前方的障碍，提前一点起跳。碰撞后鹈鹕晃动、单车轻微倾斜，随后结算面板淡入、本次得分递增，显示本次距离和历史最高分。
- 点击「再骑一次」，或松开后再次按空格，开始新一轮。结算时的空格只重开，不起跳；松开后再按空格才跳跃。
- 骑行时切换标签页或窗口失去焦点会自动暂停；回来后点击「继续骑行」或按空格继续。结算期间离开页面只冻结展示进度，回来后继续展示，不会变成骑行暂停面板。

建议使用带键盘的桌面浏览器。页面适配较窄视口，但未提供移动端专用操作。

## 碰撞与结算动画

正常动态效果下，结算使用独立于物理状态的时间轴，完整入场约 1.8 秒：

| 碰撞后的时间 | 展示行为 |
| --- | --- |
| 0—400 毫秒 | 鹈鹕围绕鸟身中心进行两次衰减晃动，单车平滑倾斜至约 6 度；结算面板不可见，也不能聚焦隐藏按钮。 |
| 400—1000 毫秒 | 结算面板从透明逐渐显现；面板可见后提供「再骑一次」按钮，本次得分暂为 0。 |
| 1000—1800 毫秒 | 本次得分从 0 按时间递增，最后精确显示真实整数；历史最高分直接展示真实结算值。 |
| 1800 毫秒以后 | 最终结果一直保留，直到主动重开；无自动关闭或自动重开。 |

相比之前碰撞后立即展示最终成绩，现在先展示角色动作，再逐步呈现结果。零分也保留完整时序；少量得分按整数变化，得分为 1 时在计分结束显示 1。动画不会推进距离、障碍、跳跃或越障计分。最高分在碰撞时立即结算保存，提前跳过动画也不会丢失新纪录。

所有阶段都可松开后重新按空格立即重开，无需看完动画。本次按键只重开，新局从地面骑行开始；松开后再按空格才跳跃。快速轻按并在新局首帧前松开也不会误跳；持续按住或自动重复按键不会起跳或连续重开。新局会清除旧局的动作、面板透明度、临时分数和播报，不会有旧动画再次覆盖画面。面板可见后也可点击按钮重开，按钮重开仍从地面骑行开始。

系统启用 `prefers-reduced-motion: reduce` 时，保留相同时序与随时重开，但关闭晃动、倾斜、淡入和数字滚动；面板在角色动作阶段结束后直接可见，最终分数在 1.8 秒时一次显示。辅助技术只在结算完成时收到一次最终成绩播报，不逐帧播报计分动画。

## 得分与最高分

每完整越过一个路锥或木箱计一分，同一障碍只计一次；跳跃次数和骑行距离不计入得分。撞到的障碍不计分，结束后本次得分冻结。按钮或空格重新开始会清空本次得分，历史最高分继续保留；暂停和继续不会结算成绩。

结束画面同时展示「本次得分」与「历史最高分」，首次没有纪录时最高分为零。仅在本次得分严格超过纪录时，使用 `localStorage` 的 `pelican-bike-adventure.bestScore` 键保存新纪录；追平或低于纪录不写入。缺失或无效的存储值按零处理，合法值为非负安全整数。

纪录仅保存在当前浏览器、当前页面的存储环境中。存储正常时，刷新同一页面仍能读取已保存的最高分；清除浏览器数据、切换浏览器或访问不同来源不会共享纪录。`file://` 页面的存储行为由浏览器决定：某些浏览器可能限制本地文件存储，移动文件后的纪录也未必相同。需要稳定的来源隔离与持久存储时，可使用固定地址的静态服务访问本目录，无需后端。

浏览器拒绝存储访问或写入失败时，游戏继续运行，结束画面提示「纪录无法保存，最高分仅在当前页面有效。」此时重开仍保留页面会话内最高分，刷新可能丢失未保存的新纪录；若此前已有成功保存的纪录，写入失败不会主动删除它。

## 自测

需要 Node.js 18 或以上版本。在本仓库目录执行：

```sh
node --test
```

不需要 `npm install`。测试覆盖起跳与落地、禁止空中连跳和长按连跳、路锥与木箱的成功越障及碰撞、结束后冻结、重新开始、障碍生成与回收、低帧率碰撞、不同帧率一致性、暂停恢复，以及页面脚本、按钮、空格和状态提示之间的连接。

成绩测试还覆盖零分、越障后碰撞结算、严格破纪录时仅写入一次、低分与同分保留纪录、按钮和空格重开、暂停期间不结算、跨页面实例读取纪录、无效存储值、最大安全整数，以及存储属性访问、读取和写入异常。页面测试通过固定随机序列和真实空格事件推进游戏，不替换计分或碰撞逻辑。

动画测试覆盖阶段边界、非法时间输入、零分与大分数、地面和空中碰撞后物理冻结、10/30/120 帧率下的阶段推进、最终结果持续停留、四阶段空格重开、碰撞当帧重开、按钮重开、长按过滤、提前重开仍保存纪录、保存失败后的会话纪录、失焦与页面隐藏恢复，以及减少动态效果和最终成绩仅播报一次。Canvas 适配器检查绘图参数有限且每帧的变换栈恢复平衡。

重开输入测试直接检查角色高度与速度：结算按空格后立即重开且保持落地，首帧前松开也不会遗留跳跃；按住、重复事件和未松开的再次按下均不能跳跃。松开后新按下可正常起跳，连续多局不会失效。页面测试在正常及减少动态效果下覆盖全部四个结算阶段，并使用真实输入与碰撞验证无后续按键时首个障碍结束本局、另一次按键能正常越障计分。

`test/browser-wiring.test.cjs` 使用 Node VM 执行真实页面脚本，并提供 DOM/Canvas 适配器；它验证输入及页面连接，不验证浏览器像素、排版或视觉辨识度。真实浏览器验收请按下表操作。

| 标准或边界 | 操作与预期结果 |
| --- | --- |
| AC1：结束显示越障得分 | 首局不跳跃，碰撞并完成约 1.8 秒结算后本次得分为 0。重开后成功越过若干障碍再碰撞，等待计分完成，本次得分应等于顶部越障数，撞到的障碍不计分；等待后分数不再变化。 |
| AC2：最高分比较与保存 | 首次取得非零分数后，两项成绩相同；随后分别完成较低、相同和较高得分回合，最高分只在较高回合结束时增加。 |

| 重开与暂停 | 分别用按钮和松开后再按空格重开，顶部越障数归零、结果区隐藏，下一次结束仍保留纪录。骑行中切换标签页再继续，不提前结算。 |
| 窄视口与长数字 | 调整视口宽度，确认结束画面两项成绩、保存失败提示和重开按钮完整可见且可操作，顶部越障数隐藏时仍能看到结束成绩。可将最高分键设为字符串 `9007199254740991` 后刷新并零分结束，确认数字完整显示、没有截断。 |
| 无效或不可用存储 | 将最高分键设为 `abc` 后刷新并零分结束，最高分为 0；随后正常越障可以保存新纪录。禁用站点存储后，确认仍可游玩和重开，结束提示无法保存，并保留当前页面会话内最高分。 |

### 碰撞动画浏览器验收

直接用现代桌面浏览器打开本目录的 `index.html`，无需安装、构建、启动服务或联网。正常动态效果下可用浏览器录屏逐帧核对时间，起点为碰撞发生时。

| 标准或边界 | 操作与预期结果 |
| --- | --- |
| AC1：角色动作及渐进结算 | 分别撞击路锥和木箱，观察约 400 毫秒的鸟身衰减晃动、单车约 6 度倾斜；随后面板用约 600 毫秒淡入，再用约 800 毫秒显示递增分数。背景和障碍不跟随旋转；跳跃中碰撞也只改变绘制表现。 |
| AC2：更长且可读的结果 | 零分及越障后碰撞各检查一次。约 1.8 秒后完整显示真实成绩，继续等待至少 10 秒，分数、面板和场景保持稳定，不自动消失。 |
| AC3：全程空格重开 | 分别在晃动、淡入、计分及最终结果阶段轻按并松开一次空格，确认立即隐藏旧面板、新局归零并贴地骑行，不自动起跳；再按空格能正常跳跃。重复多局，确认没有旧局数字、倾斜或播报残留。碰撞前已按住空格时，必须松开再按才能重开。 |
| 快速轻按及长按 | 快速轻按并松开空格重开，确认首帧及后续帧没有跳跃；长按空格重开并等待自动重复，确认没有起跳或重复重开，松开后再次按下能正常跳跃。正常及减少动态效果下均检查。 |
| 按钮与键盘焦点 | 面板隐藏时重开按钮不能获得焦点；面板可见后可以点击按钮重开。按钮获得焦点后按空格只重开一次，新局保持贴地、焦点回到游戏区域，页面不滚动；松开后再按空格才跳跃。 |
| 纪录与提前重开 | 完成破纪录回合后立即按空格跳过结算，下一次结束仍能看到新纪录。禁用存储后重复操作，游戏可继续，结算完整展示保存失败提示及会话内最高分。 |
| 失焦及切换标签页 | 在各动画阶段切走至少 5 秒后回来，展示从原进度继续，不跳过剩余阶段，也不出现「继续骑行」覆盖结算。 |
| 窄屏及长数字 | 在 320px、580px、1280px 视口检查角色动作、成绩、保存失败提示和按钮；将最高分设为 `9007199254740991` 后完成零分回合，确认完整显示，面板出现过程中高度不反复跳变。 |
| 减少动态效果与播报 | 开启系统减少动态效果设置，确认没有晃动、倾斜、渐变或连续数字滚动，约 1.8 秒后显示最终分数，仍能随时重开。开启屏幕阅读器，确认计分期间不反复播报数字，结束时仅播报一次最终成绩。 |
